# Altimates Vault Gateway

Read-only bridge from a private Custom GPT Action to the Obsidian vault generated by Graphify.

## Security model

- Obsidian Local REST API stays on loopback; it is **never** tunnelled directly.
- `OBSIDIAN_API_KEY` remains in `.env` on this Mac and is only sent to `127.0.0.1`.
- ChatGPT receives a distinct `CHATGPT_ACTION_TOKEN`, accepted only by this gateway.
- The public contract has only `GET /health`, `GET /search`, and `GET /notes/{path}`.
- The gateway accepts only Markdown notes and `graph.canvas`, rejects traversal and `.obsidian`, and limits response sizes.
- The dedicated Altimates vault runs its Local REST API on port `27125`. Never point the gateway at the parent `SecondBrain` API, even with a path prefix: its full-text search does not preserve enough path information to prove the scope.

## Local setup

1. Open `/Users/wacil/Desktop/SecondBrain/altimates` as its own vault in Obsidian, then enable **Local REST API** there. Its HTTPS port is `27125`, so it can coexist with any parent-vault plugin on `27124`.
2. Copy `.env.example` to `.env`, set the two distinct secrets, then run:

   ```zsh
   chmod 600 .env
   chmod 700 run-gateway.zsh
   ./run-gateway.zsh
   ```

3. In another terminal, verify the local surface:

   ```zsh
   curl -fsS -H "Authorization: Bearer $CHATGPT_ACTION_TOKEN" http://127.0.0.1:8787/health
   curl -fsS -H "Authorization: Bearer $CHATGPT_ACTION_TOKEN" "http://127.0.0.1:8787/search?q=Kit%20Rando"
   ```

4. To survive restarts, copy `com.altimates.vault-gateway.plist.example` to `~/Library/LaunchAgents/com.altimates.vault-gateway.plist`, then load it:

   ```zsh
   launchctl bootstrap "gui/$(id -u)" ~/Library/LaunchAgents/com.altimates.vault-gateway.plist
   ```

The service retries naturally only after a client request. Keep Obsidian running: its Local REST API is owned by the Obsidian process.

## Stable HTTPS tunnel

A Cloudflare **Named Tunnel** needs a domain managed in Cloudflare. Create a dedicated hostname such as `vault-api.example.com`; it must point only at `127.0.0.1:8787` through the tunnel.

1. Create `altimates-vault` in Cloudflare Zero Trust and authenticate `cloudflared` locally.
2. Copy `cloudflared-config.yml.example` to `~/.cloudflared/config.yml`, replacing the UUID and hostname.
3. Route the hostname and run the named tunnel:

   ```zsh
   cloudflared tunnel route dns altimates-vault vault-api.example.com
   cloudflared tunnel run altimates-vault
   ```

4. Install `cloudflared` as a service only after the two local curl checks pass.

Do not use a Quick Tunnel for the GPT: its URL changes after restarts.

## Custom GPT

1. In ChatGPT, create a GPT with visibility **Only me**.
2. In **Actions**, choose Bearer/API key authentication and set `CHATGPT_ACTION_TOKEN`.
3. Replace the server URL in `openapi.yaml` with the stable tunnel hostname and paste it into the Action editor.
4. Add this instruction:

   ```text
   For every Altimates architecture question, call searchVault first, then read the 2–6 most relevant notes. Follow relevant wikilinks. Distinguish EXTRACTED, INFERRED and AMBIGUOUS edges, cite note paths, and never claim to have read a note that was not fetched.
   ```

5. In Preview, ask: `Recherche la communauté Kit Rando Data Model, lis ses notes centrales et cite leurs chemins.`

## Freshness verification

After Graphify completes, `/health` reports the modification time of `graph.canvas`. Ask the GPT to call `getVaultHealth`, then search a newly generated or changed note. No upload or GPT reconfiguration should be necessary.
